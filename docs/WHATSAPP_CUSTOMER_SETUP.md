# חיבור WhatsApp של לקוח ל-SimpleCatch (Cloud API, חיבור ידני)

מדריך פנימי למצב הנוכחי של המערכת. מתאר איך מחברים היום מספר WhatsApp של לקוח דרך Meta Cloud API, בלי Embedded Signup.

**מקורות:** `docs/DEPLOY.md`, `docs/DECISIONS.md` (D-091, D-159), הקוד של `apps/api/src/modules/channels`, ומה שנוסה בפועל מול Meta. חלק מהמסכים והשמות של Meta נכתבו מהזיכרון וייתכן שהשתנו. מה שלא אומת מסומן ב-**[לא אומת]**.

## מה זה בעצם

המספר מחובר ל-**WhatsApp Cloud API** של Meta. SimpleCatch מקבלת ושולחת הודעות דרכו, והצוות עונה מתיבת השיחות במערכת. לכן המספר **לא יכול להיות פעיל באפליקציית WhatsApp או WhatsApp Business בטלפון**, ואם הוא פעיל שם צריך למחוק את החשבון שלו לפני החיבור.

## פעם אחת: הגדרות בשרת ובאפליקציה

1. **ב-Render** (השירות ← Environment): `WHATSAPP_PROVIDER=cloud`, `WHATSAPP_APP_SECRET` (App secret מהאפליקציה), `WHATSAPP_VERIFY_TOKEN` (מילה לבחירתך), `META_APP_ID`.
2. **באפליקציה ב-Meta for Developers:** webhook בכתובת `https://app.simplecatch.co.il/api/v1/integrations/whatsapp/webhook`, עם אותו verify token, והרשמה לשדה **messages**.
3. **אימות דו-שלבי** על חשבון הפייסבוק שלך, ואפשרות "כולם" במרכז האבטחה של העסק.

את ה-App secret והטוקנים לא שולחים בצ'אט ולא שומרים בקוד.

## דרך א: המספר בעסק שלך ב-Meta (מומלץ כרגע)

אתה מנהל את המספר עבור הלקוח, כמו סוכנות.

1. **מספר פנוי.** הלקוח מספק מספר שיכול לקבל SMS או שיחה, ושאינו פעיל באפליקציית WhatsApp.
2. **חשבון WhatsApp אמיתי** בעסק שלך ב-Meta (לא Test Messaging Account, שאינו מקבל מספרים אמיתיים). ב-Business Settings ← חשבונות ← חשבונות WhatsApp ← הוספה.
3. **הוספת המספר** ב-WhatsApp Manager ← מספרי טלפון ← הוספת מספר: מדינה (ישראל +972, בלי 0 בהתחלה), שם תצוגה, SMS או שיחה, וקוד אימות.
   - שם התצוגה צריך להתאים לעסק של הלקוח, בלי המילה WhatsApp ובלי תווים מיוחדים.
   - הסטטוס "בהמתנה" אומר שהמספר ממתין לאישור של Meta, בדרך כלל לשם התצוגה. כשהוא "מחובר" אפשר להמשיך.
4. **Phone Number ID.** מעתיקים אותו מפרטי המספר ב-WhatsApp Manager (או מ-API Setup ב-Developers).
5. **טוקן קבוע.** ב-Business Settings ← משתמשי מערכת: יוצרים משתמש מערכת, משייכים לו את האפליקציה ואת חשבון ה-WhatsApp (שליטה מלאה), ויוצרים טוקן עם `whatsapp_business_messaging` ו-`whatsapp_business_management`. הטוקן מוצג פעם אחת. טוקן קבוע אחד מכסה את כל המספרים של החשבונות המשויכים אליו, ולא צריך טוקן חדש לכל מספר. הטוקן הזמני מ-API Setup פג אחרי 24 שעות ולא מתאים.
6. **במערכת.** נכנסים לעסק של הלקוח ← הגדרות ← ערוצים ← חיבור WhatsApp, ומדביקים Phone Number ID וטוקן. המערכת בודקת אותם מול Meta ושומרת את הטוקן מוצפן.
7. **בדיקה.** שולחים הודעה למספר מטלפון אחר. היא אמורה להופיע בשיחות ולהפוך לליד (או לחכות בתיבה כ"מספר חדש" עד שמסמנים אותו עסקי או אישי).

**חסרונות:** המספר שייך לעסק שלך ב-Meta, והלקוח לא שולט בו. החשבון שלך נושא את מגבלות ההודעות ואת איכות החשבון של כל הלקוחות.

## דרך ב: המספר בעסק Meta של הלקוח

1. הלקוח מנהל עסק ב-Meta וחשבון WhatsApp משלו, עם המספר.
2. הוא משתף אותו איתך: ב-Business Settings שלו ← חשבונות WhatsApp ← המספר ← הקצאת שותף, עם **Business ID** שלך (מועתק מדף פרטי העסק, לא מוקלד) וגישה מלאה.
3. אתה יוצר טוקן של משתמש מערכת שהחשבון משויך אליו, ושאר השלבים כמו בדרך א (שלבים 4 עד 7).

**חסרונות:** בניסוי שלנו שיתוף השותף נכשל שוב ושוב עם "Unable to add a partner". לא ידועה הסיבה. **[לא אומת]**: ייתכן שקשור לוותק או לאימות של שני העסקים. התהליך ידני ודורש מהלקוח להיכנס ל-Meta.

## מה לא אפשרי כרגע

- **חיבור בלחיצה** של הלקוח עצמו (Embedded Signup). לא בנוי. דורש Tech Provider אצל Meta, וגם אימות עסק ו-App Review (D-159, D-157).
- **הודעות שאתה מתחיל** מחוץ לחלון של 24 שעות. דורשות תבניות מאושרות, שאינן נתמכות.
- **לקוחות רבים** בלי אימות עסק. המספר מוגבל ל-250 לקוחות ל-24 שעות. **[לא אומת]** שהמגבלה זהה בכל חשבון.
- **פרסום האפליקציה** ו-App Review לעמודי פייסבוק של לקוחות. דורשים עסק מאומת.

## בעיות נפוצות

| בעיה | מה לבדוק |
| --- | --- |
| "Add phone number" כבוי | החשבון שנבחר הוא Test Messaging Account. עוברים לחשבון אמיתי. |
| המספר "בהמתנה" | בדרך כלל אישור שם תצוגה. בודקים בפרטי המספר. לא מוחקים ומוסיפים מחדש. |
| הודעות לא מגיעות | בודקים webhook, הרשמה ל-messages, `WHATSAPP_PROVIDER=cloud` ו-verify token זהה. |
| החיבור מפסיק אחרי יום | הטוקן הוא הזמני (24 שעות). יוצרים טוקן קבוע. |
| "Unable to add a partner" | ראו דרך ב. לא נפתר. פותחים פנייה לתמיכה של Meta ומצרפים צילום ומזהי העסקים. |
| המספר נותק מהאפליקציה בטלפון | זה צפוי. מספר לא יכול להיות גם באפליקציה וגם ב-Cloud API. |

## מתי לעבור ל-Embedded Signup

כשיש עוסק רשום ועסק מאומת ב-Meta, ומספר לקוחות שלא כדאי לחבר ידנית. הוא מחליף את שלבים 4 עד 6 בלחיצה אחת של הלקוח, אבל לא את ה-webhook, ההודעות והשיחות, שהם אותו קוד.
